# Automated Dislocation Detection in ECCI

Code and trained models for *"Automated Dislocation Detection in Electron Channelling Contrast Imaging: A Comparative Study of Rule-Based, Neural Network, and Deep Learning Approaches"* (*APL Machine Learning*, 2026).

## Dataset
The GaN ECCI micrographs and ground-truth annotations are hosted in the link [`automated_ecci_scanners_data`](https://github.com/Aaron-Holmes/automated_ecci_scanners_data).
